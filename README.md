# Homebrew Tap

Custom Homebrew formulas by [@brunoborges](https://github.com/brunoborges).

## Install

```bash
brew tap brunoborges/tap
brew install ghcd
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| [ghcd](https://github.com/brunoborges/ghcd) | GitHub CLI Cache Proxy |
