# Homebrew Tap

Custom Homebrew formulas by [@brunoborges](https://github.com/brunoborges).

## Install

```bash
brew tap brunoborges/tap
brew install ghx
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| [ghx](https://github.com/brunoborges/ghx) | GitHub CLI Cache Proxy |
